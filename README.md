# humanstandardsystems/homebrew-tap

Homebrew tap for tools shipped by [Human Standard](https://github.com/humanstandardsystems).

## Install

```bash
brew tap humanstandardsystems/tap
brew install lens
```

## Formulae

| name | description |
|------|-------------|
| [`lens`](Formula/lens.rb) | Token-usage and cache-health tracker for Claude Code. |

## Updating

```bash
brew update && brew upgrade <formula>
```
